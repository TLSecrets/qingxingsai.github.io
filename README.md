# 心理健康离线答题训练系统
纯前端离线答题工具，无需联网、自适应手机/电脑，支持刷题、错题本、答题设置，适用于心理健康知识学习与训练。

## 功能亮点
- **离线可用**：纯 HTML + CSS + JS 单文件，打开即用
- **三种刷题模式**
  - 全部题库：完整题库随机练习
  - 随机50题：快速模拟测试
  - 错题训练：只练错题，强化薄弱点
- **智能错题本**
  - 答错自动收录
  - 答对自动移除
  - 实时显示错题数量
- **灵活答题设置**
  - 选后显示答案
  - 整页显示题目
  - 答对自动下一题
- **数据永久保存**：本地存储，关闭页面不丢失进度
- **双端自适应**
  - 电脑端：右侧悬浮控制面板
  - 移动端：底部弹窗设置，不遮挡题目

## 使用方法
1. 下载 `index.html`
2. 任意浏览器直接打开
3. 选择模式开始答题

## 适用场景
- 心理健康知识学习与复习
- 校园心理答题训练
- 自我测评与巩固练习

## 技术说明
- 纯前端实现，无后端依赖
- localStorage 持久化存储
- 响应式布局，支持手机/平板/电脑
- 题目选项随机打乱，防止死记硬背

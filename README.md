# 第十一届青心赛题库刷题工具
本项目为**第十一届青心赛心理健康题库在线刷题网页工具**，支持多模式刷题、错题本、自定义刷题设置，适配电脑端与移动端。

## 在线使用
可直接访问在线地址使用：
https://tlsecrets.github.io/qingxingsai.github.io/

## 功能特性
- 三种刷题模式：全部题库、随机50题、错题训练
- 错题自动收录，支持清空错题本
- 自定义设置：选后显示答案、整页显示题目、答对自动下一题
- 本地存储：刷题进度、错题、设置自动保存至浏览器本地
- 响应式布局：电脑端悬浮设置面板，移动端底部弹窗设置
- 选项随机打乱，防止死记硬背

## 本地运行
1. 将代码保存为 `index.html`
2. 直接用浏览器打开该文件即可使用

## 技术栈
- HTML5：页面结构
- CSS3：样式与响应式适配
- JavaScript：交互逻辑、本地存储、随机算法

## 题库范围
包含大学生心理健康、自我认知、情绪管理、积极心理学、创造力、心理资本、抗逆力、人际沟通、亲密关系、性心理、生涯规划、压力管理等相关题目，共100道选择题。
